# 🎬 Movie Catalog (Vanilla JS)

A simple movie catalog web application built using **Vanilla JavaScript, HTML, and CSS**.  
This project demonstrates dynamic DOM manipulation, filtering, and rendering without using any frameworks or external libraries.

## 📌 Features

- 🔍 Search movies by title  
- 🎭 Filter movies by genre  
- 📋 Dynamically render movie cards  
- ⚡ Real-time UI updates using JavaScript  
- 🧩 Built without frameworks (pure Vanilla JS)

---

## 🛠️ Tech Stack

- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**

No React, Vue, or other frameworks were used — the goal of this project is to practice core JavaScript fundamentals and DOM manipulation.

## 🚧 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/1LuisVargas/movie-catalog-vanilla-js.git
```

### 2. Navigate into the project folder

```bash
cd movie-catalog-vanilla-js
```

### 3. Open `index.html` in your browser

Optional: Use a local server (recommended):

```bash
npx http-server
```

---

## 💡 How It Works

- Movie data is stored locally (or fetched if connected to an API).
- JavaScript dynamically generates movie cards.
- Event listeners handle search and filtering logic.
- The DOM updates instantly without page reloads.

This project focuses on:
- Array methods (`map`, `filter`)
- Event handling
- DOM manipulation
- Clean separation of concerns
