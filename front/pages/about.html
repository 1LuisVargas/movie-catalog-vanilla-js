About this project

Movies Project is a Movie Catalog app built to practice real-world Vanilla JavaScript fundamentals: DOM manipulation, event handling, and dynamic UI updates — styled with Bootstrap for clean, responsive layouts.

Open the catalog Add a movie View repository

Quick facts

  • Stack HTML • CSS • JS
  • UI Bootstrap 5
  • Main focus DOM + Events
  • Goal JS fundamentals

What you can do

Browse movies

Explore movies displayed as responsive cards.

Add new titles

Use the form to create new movies quickly.

Update the UI instantly

Changes reflect immediately without reloading.

Responsive layout

Works well on desktop, tablet, and mobile.

How it’s built

  • Vanilla JavaScript: rendering cards, handling events, updating the view.
  • Bootstrap: grid system + components for consistent UI.
  • Clean structure: separating pages (Home, About, Contact, Add Movie).
